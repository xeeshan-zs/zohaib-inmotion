Authentication & API Keys

Currently, the API is public and does not require authentication or API keys for read access. Future write operations will require standard Bearer token authentication.

Quickstart Guide

To get started, simply make a GET request to the projects endpoint:

curl https://zohaib-inmotion.web.app/api/v1/projects.json

Sandbox Environment

A sandbox environment is available at https://sandbox.zohaib-inmotion.web.app for testing integrations without affecting production metrics.
